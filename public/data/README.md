# PLZ-Regionsdaten

`de-postal-regions.json` wird aus dem deutschen GeoNames-PLZ-Datensatz erzeugt.

- Quelle: <https://download.geonames.org/export/zip/DE.zip>
- Anbieter: <https://www.geonames.org/>
- Lizenz: Creative Commons Attribution 4.0 (CC BY 4.0)
- Nutzung: lokale Zuordnung von PLZ und Ort zu Bundesland und Landkreis; es
  werden dafür keine Grundstücksadressen an einen externen Dienst übertragen.

GeoNames stellt die Daten ohne Gewähr für Richtigkeit, Aktualität oder
Vollständigkeit bereit. Bei mehrdeutigen Kombinationen aus PLZ und Ort nimmt die
Anwendung keine Zuordnung vor.
